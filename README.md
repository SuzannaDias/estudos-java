Repositório dedicado ao registro de aprendizado, exercícios práticos e projetos desenvolvidos durante o curso **"Java Completo: Programação Orientada a Objetos + Projetos"**, ministrado pelo professor **Nélio Alves** na plataforma Udemy.
---
## 🎯 Objetivos de Aprendizado
- [x] Fundamentos da linguagem Java e sintaxe básica
- [x] Estrutura sequencial, condicional e repetitiva
- [x] Processamento de dados e operações matemáticas com `Math`
- [ ] Programação Orientada a Objetos (Classes, Atributos, Métodos)
- [ ] Construtores, Sobrecarga e Encapsulamento
- [ ] Memória, Arrays e Listas
- [ ] Tratamento de Exceções
- [ ] Banco de Dados / JDBC e Spring Boot
---
## 📂 Estrutura dos Projetos
| Projeto / Pasta | Descrição |
| :--- | :--- |
| **`Exercicios`** | Exercícios práticos de fixação (lógica, condicionais, laços e cálculos) |
| **`curso-programacao`** | Exemplos de código abordados durante as aulas teóricas |
| **`teste-processamento`** | Testes de atribuição, casting e processamento de dados |
